## Kestra MCP

Use the Kestra MCP server to search Kestra documentation and retrieve plugin or task schemas before changing workflows; verify exact fields instead of guessing. Treat the MCP server as an external third-party system: never send secrets, credentials, API keys, tokens, `.env` values, authorization headers, private filing data, or other sensitive information. Redact inputs and use placeholders; if safe redaction is impossible, do not call the server.
